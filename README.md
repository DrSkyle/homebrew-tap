# CloudSlash Homebrew Tap

Official Homebrew tap for [CloudSlash](https://cloudslash.dev) — the universal visibility, governance, and waste remediation engine.

## Installation

```bash
# Add the tap
brew tap drskyle/tap

# Install CloudSlash (provides both 'cloudslash' and 'cs' commands)
brew install cloudslash
```

Once installed, verify the installation:

```bash
cs --version
cs doctor
```

## Updating

To upgrade to the latest release:

```bash
brew update
brew upgrade cloudslash
```
